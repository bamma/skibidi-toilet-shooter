# Skibidi Bubble Blaster 🫧🚽

A kid-friendly first-person shooter in the browser, made with [three.js](https://threejs.org/).
Silly singing toilets hop into a giant bathroom. Blast them with soap bubbles to flush them away!
There is no blood or violence. Toilets spin away in a swirl of confetti, and when one reaches you, you just get splashed with water.

## Play

Open `index.html` in a modern browser. You need an internet connection because three.js loads from a CDN.
You can also host the folder on GitHub Pages; no build step is needed.

## Controls

| Desktop | Action |
|---|---|
| W A S D / arrows | Move |
| Mouse | Look & aim |
| Click (hold) | Blast bubbles |
| Space | Jump |
| Shift | Run |
| R | Refill soap |
| M | Music on / off |
| Esc | Pause |

On phones and tablets, drag on the left side of the screen to move and on the right side to look. Use the on-screen buttons to blast, jump and refill soap.

## Gameplay

- Waves get bigger each round. Green-seat toilets are fast, purple ones are big, and every 5th wave has a golden **King Toilet** boss.
- 🦆 Rubber ducks give you back a heart.
- ⭐ Stars give you a few seconds of **Super Bubbles** (rapid fire, double power, unlimited soap).
